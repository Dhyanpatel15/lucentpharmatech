# Lucent Pharmatech React Website

A responsive React/Vite recreation of the Lucent Pharmatech website. The project uses JavaScript and JSX only—there are no TypeScript or TSX source files.

## Run locally

1. Install Node.js 18 or newer.
2. Open a terminal in this project folder.
3. Install the packages:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal (normally `http://localhost:5173`).

## Create a production build

```bash
npm run build
```

The optimized website is created in the `dist` folder. The included `_redirects` and `.htaccess` files support direct links to the React pages on common static and Apache hosting platforms.
